# A MAZE ING

## Description
The goal of this project is to create a maze generator, the maze generator must parse values from a config file, be capable of providing a solution to the maze given the entry and exit positions, export the maze in a hexedeciaml format, switch between perfect and imperfect maze generation methods and above all else it must provide a method vizualise the program. the indivual cells of the maze are presented as a int value between 1-15.
this value determines which are open/broken (e.g 3 (binary value 0011) means the walls
are open to the south and west. or a binary value of 1010 means that the esat and west
walls are closed.)

## Instructions
### Getting Started
- `make install` will install all the python related dependencies from requirements.txt
- `make run` will then run the program in the current shell 
- `make lint` will run both mypy --strict . and flake8 .  
- `make build` will package the maze generation dependencies into mazegen-*.whl
- `make clean` will remove any files pyhton generated

### Config File
In the root of the repo `config.txt` exists
config.txt is used to set the default values for a variety of settings including:
- `WIDTH=INT`
- `HEIGHT=INT`
- `ENTRY=X,Y`
- `EXIT=X,Y`
- `OUTPUT_FILE=STRING`
- `PERFECT=STRING`
- `SEED=INT`

these settings can all be changed while the program is running, no need to exit and change the config

### Options
#### Algorithms
For maze generation you can choose between kruskal's algorithm and a modified DFS named DFG (Depth First Generate). 
For maze solving you can choose between BFS and DFS.

For more info on any algorithm go to [Algorithms](#algorithms-1).

## Running Headless
In order to run the maze generator as a standalone package, you can either use the provided .whl or the `make build` command which will rebuild the .whl for later installation.

once you have your package you can run `pip install mazegen-*.whl` to install the package, then you can import the generate class witch contains all the relivant funcitons for maze generation and solving.

Example:
```
from mazegen import generate

maze = generate((9,9), 42, True, None, ((0,0),(8,8)))
maze.generate_maze(0)
maze.solve(0)
print(f"{maze.draw_maze()}")

maze.solve(((0,0),(8,8)))
print(f"{maze.draw_maze()}")

usage of generate();
the parameters given should be in order of; a tuple of 2 ints holding the height and width of the maze, a int value of the seed, a boolean that represents if the maze is perfect, None which represents the style, and a tuple of 2 tuples holding 2 int values which hold the coordinates to the start and exit.


usage of .generate_maze();
give a int value which should be either 0 or 1. the value represent which algorithm to use for the generation of the maze. the default value is 0 which represents kruskals,
1 represents DFG.

usage of .solve();
give a int value which should be either 0 or 1. the value represents which algorithm to use for solving the maze. the default value is 0 which represents BFS, 1 represents DFS.
```

## Algorithms

### Maze Generation

- kruskal's algorithm
```
        kruskal was chosen primarily due to its simplicity,
        cells are selected at random and a wall is removed
        from a random direction, the neibouring cell has its
        root updated to reflect the wall breaking. This process
        is repeated until the amount of remaining valid connections 
        is zero. By the end every cell is a part of the same root 
        (appart from the cells with the 42)
```

- DFG (DFS generator)
```
        the dfs generator was chosen because of the simplicity of being
        able to implement the same logic as the dfs solver. it starts from a
        given parameter of 'start' where it will traverse through the given grid
        and will break walls according to if they are valid or not. validity
        is based on if the cells that are being checked are within bounds,
        not within the stamp and isn't within the 'seen' list which holds
        all the cells that already been visited. when there are no options
        on current cell remove current cell from the stack and back track
        to the last point where options are available.
```

- Imperfectinator
```
        The 'Imperfectinator' is a simple custom algortithm that
        loops over the entire generated maze and where ever it finds
        a dead end, it looks at the eiboring cells and randomly removes
        one, it preferentually chooses left to right but should there
        only be one option thats invalid (borders or 42) it then looks
        up and down for walls to remove. onve it has completed its checks
        it moves onto the next cell
```

### Maze Solving

- BFS
```
        BFS was used due to its simplicity to implement and its
        reliablility. from the start point it runs NESW, each cell
        visited is added into the path taken and whenever a path runs
        out of options the solver jumps back to the next valid turning
        point
```
- DFS
```
        DFS was chosen due to the close relationship it has to BFS.
        from 'start' cell we check which options are valid and add
        them to the 'stack'. validity is based on the bitvalue of the
        current cell and if the cell we are checking has not been
        visited yet. we traverse through a check if NESW are valid and if
        any of the cells are valid they get added to stack. then we 
        traverse through the stack in a LIFO way so that the last added 
        options will be the first to be checked. whenever there are
        no options around the current cell we backtrack to the last cell
        with options available. this will happen until we find the exit
        or when there is no path available. when no available path return
        empty list.
```
